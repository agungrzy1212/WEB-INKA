2. Struktur Data Tabel (Data Dictionary)

Detail skema dan informasi mengenai atribut setiap tabel pada database.

Tabel users

Nama KolomTipe DataKeterangan
idBIGINTPrimary Key, Auto Increment
nameVARCHARNama Pengguna
emailVARCHAREmail Pengguna, Unique
email_verified_atTIMESTAMPWaktu verifikasi email (Nullable)
passwordVARCHARPassword Hashed
roleVARCHARPeran pengguna (default: 'siswa')
remember_tokenVARCHARToken untuk fitur remember me
created_atTIMESTAMPWaktu data dibuat
updated_atTIMESTAMPWaktu data diupdate

Tabel courses

Nama KolomTipe DataKeterangan
idBIGINTPrimary Key, Auto Increment
nameVARCHARNama Kursus
categoryVARCHARKategori Kursus
descriptionTEXTDeskripsi Kursus (Nullable)
priceINTEGERHarga Kursus (default: 0)
durationVARCHARDurasi Kursus (Nullable)
imageVARCHARPath file gambar kursus (Nullable)
created_atTIMESTAMPWaktu data dibuat
updated_atTIMESTAMPWaktu data diupdate

Tabel registrations

Nama KolomTipe DataKeterangan
idBIGINTPrimary Key, Auto Increment
user_idBIGINTForeign Key ke tabel users (Cascade Delete)
course_idBIGINTForeign Key ke tabel courses (Cascade Delete)
nama_lengkapVARCHARNama lengkap pendaftar
tanggal_lahirDATETanggal lahir pendaftar
alamatTEXTAlamat domisili
nomer_hpVARCHARNomor Handphone
emailVARCHAREmail pendaftar
ijazah_pathVARCHARPath file upload ijazah
ktp_pathVARCHARPath file upload KTP
kk_pathVARCHARPath file upload Kartu Keluarga
pas_foto_pathVARCHARPath file upload Pas Foto
payment_receipt_pathVARCHARPath bukti pembayaran (Nullable)
statusVARCHARStatus pendaftaran (pending, approved, rejected)
admin_notesTEXTCatatan evaluasi dari admin (Nullable)
course_nameVARCHARNama kursus saat pendaftaran dilakukan
created_atTIMESTAMPWaktu data dibuat
updated_atTIMESTAMPWaktu data diupdate

Tabel news

Nama KolomTipe DataKeterangan
idBIGINTPrimary Key, Auto Increment

image_pathVARCHARPath file gambar berita (Nullable)
created_atTIMESTAMPWaktu data dibuat
updated_atTIMESTAMPWaktu data diupdate

Nama KolomTipe DataKeterangan
